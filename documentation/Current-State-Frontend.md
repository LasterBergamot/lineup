# Current State: Frontend

**Not started.** There is no frontend/UI code in the repository today — no `frontend/`,
`client/`, or `web/` directory, no `package.json`, no HTML/JS/CSS beyond the `.docx`
document template itself. The backend is consumed directly via its REST API (see
[[Current State: Backend]]) and its interactive Swagger docs at `/docs`.

The only mention of a frontend anywhere in the project's planning docs is a single
forward-looking line about a future OAuth integration ("Frontend initiates OAuth flow via
`@supabase/supabase-js`") — that's a plan, not existing code.

See [[Roadmap: Frontend]] for what's planned.
